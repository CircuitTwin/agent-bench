## Bug descriptions

| case | version | description |
|---|---|---|
| baud | v1 | BRR=0x16C computed for an unconfigured 42 MHz APB1; the line runs at about 44 kbaud against a 115200 peer |
| clk_gpio | v1 | GPIOD clock (AHB1ENR bit 3) never enabled; the port ignores writes and reads 0 on silicon |
| clk_timer | v1 | TIM3 clock (APB1ENR bit 1) never enabled; CNT stays 0 on silicon |
| dma_m2m | v1 | DMA2 clock never enabled |
| dma_m2m | v2 | FIFO direct mode left on (DMDIS=0); memory-to-memory needs the FIFO |
| dma_m2m | v3 | NDTR left at 0, so the stream has nothing to transfer |
| gpio_mode | v1 | MODER written at bit 12 (the pin number) instead of bit 24 (2 x pin); the pin stays an input |
| i2c_nack | v1 | unbounded wait for ADDR; AF is never looked at |
| i2c_nack | v2 | bounded wait, AF never checked, the read is reported as done |
| irq_chain | v1 | NVIC ISER bit for TIM3 never set |
| irq_chain | v2 | TIM3 DIER.UIE never set |
| irq_chain | v3 | handler never clears UIF; it re-enters forever and starves main |
| irq_chain | v4 | handler name misspelled, so the vector keeps the default handler |
| nvic_prio | v1 | TIM3 priority 0 equals SysTick priority 0: no preemption, the wait inside the handler times out |
| pll | v1 | FLASH_ACR wait states never set; silicon runs 168 MHz code from flash with 0 wait states and faults or misreads |
| pll | v2 | SW written and SWS read at once, without waiting for PLLRDY |
| poll_flag | v1 | unbounded poll on USART2 RXNE (no byte is ever received) instead of TC |
| psc | v1 | PSC=16 (divide by 17) instead of 15: a 5.9% slow timebase |
| race | v1 | two-word read without masking interrupts; torn when SysTick fires between the loads |
| reset_vals | v1 | assumes SRAM reads 0 at power-up; the vendor documents it as undefined |
| ro_write | v1 | writes GPIOD_IDR (read-only) instead of BSRR |
| ro_write | v2 | stores to flash at 0x08008000 without unlocking or programming it |
| stack | v1 | depth 4000 x about 80 bytes outruns the 128 KB SRAM and runs below 0x20000000 |
| unaligned | v1 | LDRD at an address 2 mod 8 (always a UsageFault on Cortex-M4) |
| unaligned | v2 | CCR.UNALIGN_TRP set, then a word load at buf+1 (UsageFault) |
| wdg | v1 | loop never writes IWDG_KR=0xAAAA; silicon resets after 31 ms |
